# Brand assets

A wireframe PDU icon for this integration.

| File | Size | Purpose |
|---|---|---|
| `icon.png` | 256×256 | Integration icon |
| `icon@2x.png` | 512×512 | hDPI icon |
| `logo.png` | 512×512 | Logo (same artwork) |

These are **not** loaded from this repository. For them to show up in the Home
Assistant UI, they must be submitted to the
[home-assistant/brands](https://github.com/home-assistant/brands) repository:

```
custom_integrations/cyberpower_pdu/icon.png
custom_integrations/cyberpower_pdu/icon@2x.png
custom_integrations/cyberpower_pdu/logo.png      # optional
```

Until that PR is merged, Home Assistant shows a generic placeholder icon — the
integration works regardless.

The artwork is generated by `scratch/gen_icon.py` (Pillow); transparent
background, single tech-blue stroke.
